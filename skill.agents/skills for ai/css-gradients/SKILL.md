# CSS Gradients & PeachWeb Color Grading Skill

PeachWeb and modern UI color grading emphasize rich dark backgrounds, HSL color harmony, and subtle multi-layered radial light fields.

## Core Color Grading Rules

1. **HSL Color Palette for Flood Rescue System**:
   - **Deep Midnight Background**: `hsl(222, 47%, 6%)` (`#060b19`)
   - **Electric Ocean Cyan (Primary)**: `hsl(199, 89%, 48%)` (`#0ea5e9`)
   - **Emerald Safety (Safe Zone)**: `hsl(160, 84%, 39%)` (`#10b981`)
   - **Crimson Emergency (Critical Alert)**: `hsl(354, 84%, 57%)` (`#ef4444`)
   - **Amber Warning (Caution Zone)**: `hsl(38, 92%, 50%)` (`#f59e0b`)

2. **21st.dev Floating 3D Button Gradient Formula**:
   - Primary: `linear-gradient(135deg, #0ea5e9 0%, #0284c7 100%)`
   - Secondary: `linear-gradient(135deg, #10b981 0%, #059669 100%)`
   - Emergency: `linear-gradient(135deg, #ef4444 0%, #dc2626 100%)`
   - Border: `1px solid rgba(255, 255, 255, 0.2)`
   - Shadow: `0 8px 20px rgba(..., 0.35)`

3. **Glassmorphism Backdrop Filter**:
   - Surface: `rgba(15, 23, 42, 0.82)`
   - Border: `1px solid rgba(56, 189, 248, 0.25)`
   - Filter: `backdrop-filter: blur(24px); -webkit-backdrop-filter: blur(24px);`
